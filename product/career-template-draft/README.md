# folio ゲーム業界志望者向けポートフォリオテンプレート

HTML/CSSを編集して、ご自身の作品・経験を紹介するポートフォリオを作るためのテンプレートです。サンプルはゲーム業界を目指す架空の学生を想定しています。

## ファイル

- `index.html` — ポートフォリオの編集元
- `css/style.css` — レイアウトと見た目
- `images/work01.png`〜`work03.png` — レイアウト確認用のサンプル画像
- `LICENSE.txt` — 利用条件

## 使い方

1. ZIPを展開し、`index.html` をブラウザーで開きます。
2. `[ ]` で囲まれた文言を自分の情報に差し替えます。
3. `images` 内の画像を、自分が公開する権利を持つ作品画像へ差し替えます。同じファイル名を使うとHTMLの変更は不要です。
4. `your-email@example.com` を自分が公開してよい連絡先へ変更します。
5. `index.html`、`css`、`images` をまとめてウェブ公開します。ホスティングサービスの利用条件や公開手順は各サービスで確認してください。

## 公開前の確認

- `[ ]` の仮文言や架空のプロフィールが残っていないか
- サンプル画像を、自分が公開する権利を持つ画像に差し替えたか
- 連絡先を正しく設定したか
- スマートフォンで文字や画像が読めるか

Google Fontsを読み込みます。フォントが取得できない場合は端末の標準フォントで表示されます。個別の編集サポート、公開作業、制作代行は商品に含まれません。
